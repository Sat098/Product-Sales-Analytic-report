📊 Product Sales Dataset

📌 Project Overview

This project is a Power BI dashboard created to analyze product sales data.
The dashboard provides insights into sales performance across states, products, customers, and categories.

It helps understand which products and segments contribute most to overall sales.

📊 Dashboard Features
- Sales analysis by State
- Category comparison (Electronics vs Furniture)
- Product-wise sales performance
- Customer and segment analysis (Online, Retail, Corporate)
- Drill-through feature for detailed product insights
- Map visualization showing customer locations
